# Mess Manager 2.0

## About the Project

Mess Manager 2.0 is a web-based application developed to simplify and manage daily mess activities. The system helps users manage members, meals, deposits, expenses, and monthly calculations efficiently.

This project was developed collaboratively by our team.

## Features

- User Registration and Login
- Create and Join Mess
- Member Management
- Meal Tracking
- Deposit Management
- Expense Management
- Monthly Expense Calculation
- Monthly Details
- Profile Management
- Change Mess Manager
- Password Reset Functionality

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
